# Seoulicious Toronto

Static site. `index.html` is the entry point; `assets/seoul-skyline-bw.png` is a locally bundled art asset. No build required.

## Deploy

GitHub repo -> Cloudflare Pages; framework None, build command empty, output directory `/`.

## Preview status

The HTML includes `<meta name="robots" content="noindex, nofollow">` until final owner approval. **Remove it before switching the production domain.**

Menu prices, opening hours, reviews, owner statements, images and ordering links need owner sign-off before production. Food photography and the logo are currently loaded from third-party hosts and should be moved into repo-owned assets before production.

The prototype deliberately links reservations and full menu back to Seoulicious's existing website, so do not decommission the Wix site until equivalent services are migrated.
